## GÖREV BE-10 — worker'a env-bayraklı fixture modu

**Amaç:** arq worker'ın keşif job'unu, gerçek dış API anahtarı olmadan, SEC fixture'larıyla
uçtan uca yürütebilmesi. Canlı Places/IG/Apify çağrısı **yok** (kural 6) — fixture modu bunu
zaten garantiler.

**Oku:** `docs/TASKS.md` `## Bloke` → FE-4-B2 (sorunun tam tanımı), `## Biten` → BE-9 satırı
(worker, `run_discovery`, adaptör client enjeksiyonu nasıl kurulu). `api/worker.py`,
`api/services/discovery.py`, `api/adapters/*`. `tests/fixtures/README.md` (handle→profil
eşleme yapısı).

**Sorun (FE-4-B2):** `api/worker.py` gerçek `PlacesAdapter(api_key=…)` kuruyor;
`GOOGLE_PLACES_API_KEY` yoksa iş anında `error`. `discover_demo` fixture kullanıyor ama
worker'ı atlıyor. Worker'da fixture'a çevirecek bayrak yok → canlı job akışı done'a ulaşamıyor.

**Dokunabileceğin dosyalar:** `api/**`, `.env.example`

**Yapılacaklar:**
- Bir ayar bayrağı (ör. `RADAR_FIXTURE_MODE`, `pydantic-settings`). Açıkken worker'ın keşif
  job'u adaptörlere **fixture-besleyen sahte HTTP client** (BE-9 demo'sunun MockTransport'u)
  enjekte eder; kapalıyken gerçek client (üretim yolu) kullanılır.
- Fixture modunda job normal akışı yürütür: enqueue → `queued` → `running` → Places fixture
  keşfi → upsert → handle eşleme → profil fixture çekimi (BD→Apify fallback) → snapshot persist
  → (Faz 3'te BE-11 tetikleme fazı eklenince skorlama) → `done` + sonuç özeti. **Worker atlanmaz**
  — `discover_demo`'dan farkı bu: gerçek job/durum makinesi çalışır.
- `.env.example`'a bayrağı **değersiz** (veya `false` varsayılan) ekle. Üretimde kapalı,
  test/yerel/CI'da açık.
- Fixture kaynağı `tests/fixtures/`'ten okunur; worker `tests/`'e **yazmaz**, sadece okur.
  (Fixture yolu ayar/sabit olabilir; `api/` fixture kopyası tutma, tek kaynak `tests/fixtures/`.)

**Yapmayacakların:**
- Fixture modunu üretimde varsayılan açık yapma — yanlışlıkla sahte veri sunar.
- Gerçek anahtarla canlı çağrı yolu ekleme/test etme (kural 6).
- `tests/` altına yazma (güvenlik sahipliği). Kalıcı test SEC'in; sen elle doğrula.
- Yasak metrik alanı taşıma (kural 7).

**Kabul kriterleri:**
- `RADAR_FIXTURE_MODE` açıkken: gerçek arq worker + `POST /discovery/run` → `job_id` anında;
  `GET /jobs/{id}` `queued→running→done` ilerliyor; sonuç özeti ~20 işletme / snapshot sayısı
  içeriyor. **Hiçbir `GOOGLE_PLACES_API_KEY`/Apify token'ı gerekmiyor** ve hiçbir canlı çağrı
  yapılmıyor. Elle doğrula (worker + curl akışı), sayıları kapanış notuna yaz.
- Bayrak kapalıyken worker gerçek client kuruyor (üretim yolu bozulmamış) — kod yolu var,
  anahtarsız ortamda beklenen `error`'a düşmesi normal.
- `ruff check .` + `ruff format --check` + `mypy api/` + `pytest` yeşil (CI pin'leri).
- `git grep -nE "impressions|reach|saves|profile_views|profile_visits|demographics" -- api/` boş.
- `.env.example`'da bayrak değersiz/false; gerçek anahtar sızıntısı yok.
